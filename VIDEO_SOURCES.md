# AIQ Academy — Video Sources

The AIQ Academy video library keeps playback inside the academy through an embedded YouTube player. Each card includes the video title, channel, category, language badge, source URL, and a copy-link action. The **Watch inside site** action opens the video in the academy modal; the source URL is available separately when the user explicitly wants to open YouTube.
